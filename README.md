# 🛰️ Algoritmo de Dijkstra con Interfaz Gráfica en Python

Este proyecto implementa el algoritmo de Dijkstra para calcular caminos mínimos en grafos dirigidos y ponderados.
Incluye una interfaz gráfica moderna, construida con PyQt5, que permite:

Crear matrices de adyacencia personalizadas

Definir nodos de inicio y destino

Calcular el camino más corto

Visualizar el grafo con nodos distribuidos en círculo

Ver pesos, flechas y distancias de manera visual

📌 Características principales

✔️ Implementación limpia del algoritmo de Dijkstra

✔️ Interfaz moderna con estilos personalizados (QSS)

✔️ Editor visual de matrices de adyacencia

✔️ Detección de valores inválidos y pesos infinitos

✔️ Visualización dinámica del grafo con nodos y aristas
